# BudgetTrackerApp

A straightforward Android program that allows users to monitor their income, expenditures, and other financial information.
a summary of the whole budget, including financial objectives.

 Features

User login and registration (Room Database)
Add income and expenses
View financial records
View totals and summaries
Set and track savings goals
Logout functionality
Bottom navigation for easy navigation

Tech Stack

Kotlin
Android SDK
Room Database (SQLite)
Navigation Component
ViewBinding
Material Design Components

Project Structure

    com.example.budgettrackerapp
    
    Login & Register
    Home screen
    Add income/expense
    View transactions
    Summary screen
    Savings goals
    Database Access Objects
    Room entities
    Database setup
    Archievements
    Goals
    Graph
    uploading images and save
